# Reference reels

Videos you save from the Reel builder page's drop zone land here, one folder
per reference: `reference_reels/<ref_id>/<original filename>`.

These are stored for your own reference while shooting - **the agent never
watches the video file.** There's no vision step in this pipeline. The build
works entirely from the notes you write when you save the reference ("what to
copy": the hook, the pacing, the structure, a specific mechanic) plus the
source URL if you gave one. Write a real note, not just "like this one" - the
more specific the note, the closer the generated script matches what you
actually liked about the reference.

Video files aren't committed to git (see `.gitignore`) - only this README and
the folder are. Keep your own backup of the originals.
