# Reference posts

Images you save from the Post builder's "Copy a specific structure" section
land here, one folder per reference: `reference_posts/<ref_id>/<original
filename>`.

These are stored for your own reference - **the agent never analyses the
image.** There's no vision step in this pipeline. The build works entirely
from the note you write when you save the reference (the structure to copy:
a Q&A format, a ranked countdown, a this-or-that comparison, whatever it is)
plus the source link if you gave one. Describe the structure, not just "like
this one" - the more specific the note, the closer the generated carousel
matches the layout you actually liked.

Leave the whole reference section empty in Post builder and you get PubCam's
proven default layout (SAVE-THIS cover, one item per slide, payoff, outro) -
this is only for when you want to copy something different.

Image files aren't committed to git (see `.gitignore`) - only this README
and the folder are. Keep your own backup of the originals.
