# Welcome to Notes

Tags: meta

Freeform notes and knowledge - venue info, old Notion pages, half-formed
ideas, whatever's useful to remember. Manage these from the Notes page in
the app (create, edit, tag, search), or open any file here by hand - it's
the exact same file either way.

This is context the agent reads (see CLAUDE.md), not something it writes
to on its own - same trust level as the Google Drive sheets in Section 1.
If something in a note is wrong or stale, edit it directly; don't wait for
a rebuild or a script.
